# 架构说明

`internet-rss-content-aggregator` 提供一套**内容自动聚合**参考实践：编排函数按定时或手动触发，完成「获取 feed → 抓取文章元信息 → 与已有条目去重 → 输出聚合列表」，前端静态站读取聚合数据展示。适用于内容站、博客聚合、信息流等「自动收编 + 静态展示」场景。

## 架构图

```
                            ┌────────────┐
                            │  定时触发  │
                            └──────┬─────┘
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                     FunctionGraph orchestrator                     │
│                获取 feed → 抓取元信息 → 去重 → 输出                │
└──────────────────────────────────┬─────────────────────────────────┘
                                   │ items
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                       内容数据 content.json                        │
└──────────────────────────────────┬─────────────────────────────────┘
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                  OBS 静态托管（前端展示聚合内容）                  │
└────────────────────────────────────────────────────────────────────┘
```

## 核心组件

| 组件 | 说明 |
|---|---|
| FunctionGraph `orchestrator` | 一次执行完成聚合流水线：获取 feed 列表 → 抓取文章元信息 → 与现有条目去重 → 输出新增 items |
| OBS 静态桶 | 托管前端静态站（index.html + content.json），公网可访问 |

## 编排流程

1. 触发：手动调用或控制台配置定时触发器（cron）
2. 聚合：`source=mock` 使用内置示例（无网络）、`source=live` 真实抓取（函数需公网出口）
3. 去重：按文章 `link` 与已有 items 比较，仅输出新增条目，返回 `{items, total, duplicates}`
4. 展示：聚合结果写入前端数据文件（真实环境建议接入对象存储或缓存持久化），静态站渲染

## 设计说明

- 聚合逻辑集中在单函数，避免函数间编排复杂度，便于替换与扩展
- 前端为零构建静态站（原生 HTML/JS + JSON），可直接托管
- 真实生产把持久化层接入对象存储（需委托可用）或缓存服务，见文档说明
